# Serving dependencies, installed ON the G4dn instance by cloud-init.
#
# Not installed locally: jax[cuda13] resolves to x86_64 CUDA wheels sized for a
# GPU host, which are wrong (and enormous) on a control-plane machine.
# server.py's _SERVING_REQUIREMENTS is the source of truth for what the bootstrap
# actually installs; this file mirrors it and a test asserts they match.
#
# The PROFILER is NOT here. xprof and tensorboard are installed by the same
# bootstrap but as their own non-fatal stage, mirrored by
# requirements-profiling.txt against _PROFILING_REQUIREMENTS. The split is the
# point: a failure in this file must stop the install, and a failure in that one
# must not.
#
# jax[cuda13] pulls CUDA from pip (cublas, cudnn, cuda-runtime, cusolver), so
# the DLAMI only has to supply the driver -- no CUDA toolkit, no compiler, no
# Rust. Requires Python >= 3.12; the rig installs the newest stable line
# (see tpu.env).
jax[cuda13]
fastapi
uvicorn
pydantic
transformers
# Chat-template rendering for transformers. A missing jinja2 leaves /health
# green and fails every generation with a 500 (measured 2026-08-19).
jinja2
safetensors
huggingface_hub
numpy
