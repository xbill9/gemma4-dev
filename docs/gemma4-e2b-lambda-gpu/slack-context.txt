AWS Lambda gained GPU instances on 2026-11-18 (Lambda Managed Instances). On day one, Gemma 4 E2B with Google's QAT 4-bit weights runs inside a Lambda function on one g6.2xlarge (NVIDIA L4) from AWS's vLLM image, with a local chat page that calls it through lambda invoke.
One environment took 48 requests at once, up to 3,614 output tokens per second with none failing; Google's drafter made a single reply 1.63x faster and cost throughput from 16 requests up.
